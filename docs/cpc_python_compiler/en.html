About this application

Python Compiler turns Python programs into Windows programs with PyInstaller,
tests them, and publishes them. It follows one flow:

Code Browser or Gateway Apps (the Python source) > Temp Compile (the build and
test files) > Outputs (test, then publish) > Compile Apps (the finished apps,
the Start Menu and the new gateway entry).

Code Browser compiles Python files from any folder. Gateway Apps compiles the
apps listed in your gateway file (gateway.json). Both lists let you read the code
with a right click. Outputs tests what was built and publishes it. Log records
everything that happens. The line at the bottom of the window always shows the
last action and its result, the running job, and the Cancel buttons.

Compiling is a batch job that runs in the background, so the window stays usable.
Press Compile again while a job is running and the new job joins the queue.

Start in Code Browser: pick a folder, select a Python file, and press Compile
Selected. Then open Outputs to try the result, and publish it when you are happy.
Set your folders in Config. Click any Notes heading to open its corresponding
tab.

Compile Python files straight from a folder. Folder shows the current folder.
Type a path or choose one of your recent folders from the drop-down. Browse...
chooses a folder, Up moves to its parent, Default goes to the default folder set
in Config, and Refresh reads the folder again. Only the files directly in the
folder are listed. Every folder you open is added to the recent list
automatically.

Compile Selected compiles the selected files. Compile All Shown compiles every
file in the list, so use Search first to narrow it down. One File packs each
program into a single exe, Windowed hides the console window, Clean removes
PyInstaller's old build files first, and No UPX skips the UPX compression step,
which is slow and often only produces warnings. These four choices are shared
with Gateway Apps. Only .py and .pyw files are compiled. Each press makes one job: if another
job is running it waits its turn. Cancel Job stops the running job, and Cancel
All also clears the queue.

Type in Search to show only the files whose names contain that text; X clears the
box. The .py / .pyw only box hides other kinds of file. The list shows the file
name, when it was created and last modified, and its size. The most recently
changed file is at the top; click a column heading to sort differently.

If a Python file has an English help file beside it (name.en.txt, or the name
without a cpc_ prefix), it is built into the exe, so the Notes tab of the
compiled program always has its English text. The compile log shows
"Embedding help".

Right click a file to see code. A window opens with the code and line numbers.
Copy All copies the whole text, Open File opens it in your usual editor, and
Close (or the Esc key) shuts the window. A file over 1 MB shows only its first
megabyte, and binary files are not shown. The preview cannot change the file.

The CSV and HTML buttons at the top right export the files shown, in the order
shown. A file is never overwritten; if the name is taken, the date and time are
added to the new name.

Compile the apps listed in your gateway file (gateway.json). Only Python files
(.py and .pyw) are shown. Reload Gateway reads the file again, and Project limits
the list to one project, or All.

Select one or more apps, then press Compile Selected. Compile All Shown compiles
every app currently in the list. One File, Windowed, Clean and No UPX work as in
Code Browser. Each compile is written to its own folder under the Temp Compile output
root set in Config.

Click a column heading to sort. Right click an app to see its code. The CSV and
HTML buttons at the top right export the list exactly as it is shown, including
your sort order.

A running record of every job: when it was queued and started, each app's
PyInstaller output (indented), how long each app took, and the result. Lines are
marked with the job number, such as [Job 3 2/5], meaning the second of five apps
in job 3.

Each job is also saved as its own log file in the logs folder under the Temp
Compile output root, and its path is shown when the job ends. Clear Log empties
the window only. The window keeps the latest 5000 lines.

The table lists what you have compiled in this session, from Code Browser or
Gateway Apps: the app, its Python source, the executable result, the Result
(Queued, Running, Compiled, Failed or Cancelled) and where it has been
Published. Rows change as the job runs, and your sort order is kept.

Test Selected PY runs the Python source and Test Selected EXE runs the compiled
program from Temp Compile. They use the rows you select here; if none are
selected, they use the files selected in the list you used last. Open Temp
Compile shows the build folder in the file manager, and Clear Results empties the
table. The CSV and HTML buttons export it.

Test the exe first, then publish it. Both publish buttons work on the selected
rows that show Compiled. Each one first copies the app into its own folder in
Compile Apps, with the exe and its settings json. The settings json is copied
from beside the Python file only if the app does not have one there yet, so
settings you have already changed are never overwritten. Help files in other
languages (name.fr.txt and so on) are copied beside the exe in the same way. They
are external on purpose, so a language can be added or corrected without
compiling again. The English help file is not copied because it is built into the
exe. Then:

Update Gateway replaces the Python file in gateway.json with the link to the
copied exe. It asks first, keeps a backup called gateway.json.bak, and adds an
entry if the app was not in the file. The Python source is kept in the entry
as source_py, so the app stays in Gateway Apps and can be compiled again.

Add Start Menu adds a shortcut to the copied exe in your Start Menu. The shortcut
is named after the app (the app_name in the gateway entry, or the file name for
a file from Code Browser), and is placed in the Start Menu folder set in Config.
If the shortcut is already there it is updated.

Run them again after a new build to update the same entries. If the copy fails,
close the running app and try again. They run as jobs, like compiling, so they
queue behind a running compile. Open Compile Apps shows the Compile Apps folder.

Config follows the flow of the program, top to bottom. Save Settings at the
bottom writes every setting to the settings file and shows where it was saved.

Code Browser (raw folders): Default folder is the folder Code Browser opens
first. Browse... chooses it and Use Current takes the folder Code Browser is
showing now. Recent folders lists the folders you have used, newest first, and
the last 15 are kept. Every folder you open in Code Browser is added
automatically. Type or pick a folder and press Add to put it in the list, Remove
to take it out, or Open to show it in Code Browser.

Gateway (source list): the file that lists your apps for Gateway Apps. Browse...
chooses it, Default goes back to gateway.json in the program's folder, and Reload
reads it again. Nothing is compiled or copied here.

Temp Compile: Output root is where the build, dist and spec folders and the job
logs go, one folder per app. These are temporary files for testing, not the
finished app. Python (PyInstaller) is the python.exe used to run PyInstaller and
the Python tests. It is only needed when this program is itself an exe, because
an exe cannot run PyInstaller. Leave it empty to use the Python found on the PATH.

Compile Apps: Apps folder is where the finished apps live, each in its own folder
with its exe and settings json. The Start Menu shortcut and the new gateway entry
point to this copy. Start Menu folder is the name of the folder the shortcuts are
added to. When you choose a new Apps folder with Browse..., you are asked
whether to keep the settings file there too.

When this program is itself an exe, its English help is built in. On the first
start a copy is placed beside the exe so it can be edited; it is never replaced,
and deleting it brings the built-in text back. Help in other languages is a plain
file beside the exe.

Settings file: shows where this program's own settings (python_compiler.json)
are kept. They start in the same folder as the program (the exe, or this
script), never in a temporary folder. Browse... chooses another folder, Use Apps
Folder moves it to the Compile Apps folder, and Default moves it back to the
program's folder. The current settings are saved in the new place and the
program's folder keeps a small note saying where they are, so the next start
finds them. The old copy is left where it was. If the settings folder is not
available at start (for example a network drive), default settings are used and
the note is kept.

Colours, density and window size are in UI Choices.

Choose the colour theme, density and window size. Use Current Size takes the size
of the window as it is now, and Apply + Save applies and saves your choices. The
list stripes follow the theme you choose. These settings control how the app
looks. The folders and options belong in Config.

Use the shared launcher to open registered applications, files, folders and
links. It keeps its cards in gateway_cards.json in the program's folder. Gateway
is separate from the gateway file that supplies the Gateway Apps list.

Python Compiler, PyInstaller ব্যবহার করে Python প্রোগ্রামকে Windows প্রোগ্রামে রূপান্তর করে, পরীক্ষা করে এবং প্রকাশ করে। এর কাজের ধাপ হলো:
Code Browser অথবা Gateway Apps (Python সোর্স কোড) > Temp Compile (বিল্ড ও পরীক্ষার ফাইল) > Outputs (পরীক্ষা, তারপর প্রকাশ) > Compile Apps (সম্পূর্ণ অ্যাপ, Start Menu এবং নতুন Gateway এন্ট্রি)।
Code Browser যেকোনো ফোল্ডার থেকে Python ফাইল কম্পাইল করে। Gateway Apps আপনার gateway ফাইলে (gateway.json) তালিকাভুক্ত অ্যাপগুলো কম্পাইল করে। দুই তালিকাতেই ডান ক্লিক করে কোড দেখা যায়। Outputs তৈরি হওয়া ফলাফল পরীক্ষা করে এবং প্রকাশ করে। Log-এ সব ঘটনা সংরক্ষিত হয়। উইন্ডোর নিচের লাইনটি সব সময় সর্বশেষ কাজ ও তার ফলাফল, চলমান কাজ এবং Cancel বোতামগুলো দেখায়।
কম্পাইল একটি ব্যাচ কাজ, যা পেছনে চলে; তাই উইন্ডো ব্যবহার করা যায়। একটি কাজ চলার সময় আবার Compile চাপলে নতুন কাজটি সারিতে যুক্ত হয়।
Code Browser থেকে শুরু করুন: একটি ফোল্ডার বেছে নিন, একটি Python ফাইল নির্বাচন করুন এবং Compile Selected চাপুন। এরপর ফলাফল পরীক্ষা করতে Outputs খুলুন এবং সন্তুষ্ট হলে প্রকাশ করুন। Config-এ আপনার ফোল্ডার নির্ধারণ করুন। যেকোনো Notes শিরোনামে ক্লিক করলে সংশ্লিষ্ট ট্যাব খুলবে।

একটি ফোল্ডার থেকে সরাসরি Python ফাইল কম্পাইল করুন। Folder বর্তমান ফোল্ডার দেখায়। একটি পাথ লিখুন অথবা ড্রপ-ডাউন তালিকা থেকে সাম্প্রতিক ফোল্ডার বেছে নিন। Browse... ফোল্ডার নির্বাচন করে, Up তার parent ফোল্ডারে যায়, Default Config-এ নির্ধারিত ডিফল্ট ফোল্ডারে ফেরে এবং Refresh ফোল্ডারটি আবার পড়ে। শুধু ওই ফোল্ডারের সরাসরি ভেতরে থাকা ফাইলগুলো দেখানো হয়। আপনি যে ফোল্ডারই খুলুন, সেটি স্বয়ংক্রিয়ভাবে সাম্প্রতিক তালিকায় যুক্ত হয়।
Compile Selected নির্বাচিত ফাইলগুলো কম্পাইল করে। Compile All Shown তালিকার প্রতিটি ফাইল কম্পাইল করে, তাই তালিকা ছোট করতে আগে Search ব্যবহার করুন। One File প্রতিটি প্রোগ্রামকে একটি exe ফাইলে প্যাক করে, Windowed কনসোল উইন্ডো লুকায়, Clean প্রথমে PyInstaller-এর পুরোনো বিল্ড ফাইল সরায় এবং No UPX UPX কম্প্রেশন ধাপ বাদ দেয়; এটি ধীর এবং প্রায়ই শুধু সতর্কবার্তা তৈরি করে। এই চারটি বিকল্প Gateway Apps-এর সঙ্গেও অভিন্ন। শুধু .py এবং .pyw ফাইল কম্পাইল হয়। প্রতিবার চাপলে একটি কাজ তৈরি হয়: অন্য কাজ চললে এটি নিজের পালার জন্য অপেক্ষা করে। Cancel Job চলমান কাজ থামায়, আর Cancel All সারিও খালি করে।
Search-এ লিখলে শুধু সেই ফাইলগুলো দেখায় যাদের নামে ওই লেখা আছে; X বাক্সটি খালি করে। .py / .pyw only বাক্স অন্য ধরনের ফাইল লুকায়। তালিকায় ফাইলের নাম, তৈরির তারিখ, সর্বশেষ পরিবর্তনের তারিখ এবং আকার দেখানো হয়। সর্বশেষ পরিবর্তিত ফাইলটি ওপরে থাকে; সাজানোর ধরন বদলাতে কলামের শিরোনামে ক্লিক করুন।
কোনো Python ফাইলের পাশে ইংরেজি সহায়তা ফাইল থাকলে (name.en.txt, অথবা cpc_ উপসর্গ ছাড়া একই নাম), সেটি exe-এর মধ্যে যুক্ত হয়। তাই কম্পাইল করা প্রোগ্রামের Notes ট্যাবে সব সময় ইংরেজি লেখা থাকে। কম্পাইল লগে "Embedding help" দেখায়।
কোড দেখতে ফাইলে ডান ক্লিক করুন। কোড ও লাইন নম্বরসহ একটি উইন্ডো খুলবে। Copy All পুরো লেখা কপি করে, Open File আপনার নিয়মিত এডিটরে ফাইলটি খোলে এবং Close (অথবা Esc কী) উইন্ডো বন্ধ করে। ফাইল 1 MB-এর বড় হলে শুধু প্রথম এক মেগাবাইট দেখানো হয়; বাইনারি ফাইল দেখানো হয় না। প্রিভিউ ফাইল পরিবর্তন করতে পারে না।
উপরের ডানদিকের CSV ও HTML বোতাম দৃশ্যমান ফাইলগুলো প্রদর্শিত ক্রমে রপ্তানি করে। কোনো ফাইল কখনো ওভাররাইট হয় না; নাম আগে থেকে থাকলে নতুন নামে তারিখ ও সময় যোগ হয়।

আপনার gateway ফাইলে (gateway.json) তালিকাভুক্ত অ্যাপগুলো কম্পাইল করুন। শুধু Python ফাইল (.py এবং .pyw) দেখানো হয়। Reload Gateway ফাইলটি আবার পড়ে এবং Project তালিকাটি একটি প্রকল্প অথবা All-এ সীমাবদ্ধ করে।
এক বা একাধিক অ্যাপ নির্বাচন করে Compile Selected চাপুন। Compile All Shown বর্তমানে তালিকায় থাকা সব অ্যাপ কম্পাইল করে। One File, Windowed, Clean এবং No UPX Code Browser-এর মতোই কাজ করে। প্রতিটি কম্পাইল Config-এ নির্ধারিত Temp Compile আউটপুটের মূল ফোল্ডারের অধীনে নিজস্ব ফোল্ডারে লেখা হয়।
সাজানোর জন্য কলামের শিরোনামে ক্লিক করুন। কোড দেখতে কোনো অ্যাপে ডান ক্লিক করুন। ওপরের ডানদিকের CSV ও HTML বোতাম তালিকাটি ঠিক যেভাবে দেখানো হয়েছে, সেই ক্রমসহ রপ্তানি করে।

প্রতিটি কাজের রেকর্ড: কখন সারিতে রাখা হয়েছে এবং শুরু হয়েছে, প্রতিটি অ্যাপের PyInstaller আউটপুট (ইন্ডেন্টসহ), প্রতিটি অ্যাপে কত সময় লেগেছে এবং ফলাফল। লাইনে কাজের নম্বর থাকে, যেমন [Job 3 2/5], অর্থাৎ job 3-এর পাঁচটি অ্যাপের মধ্যে দ্বিতীয়টি।
প্রতিটি কাজ Temp Compile আউটপুটের মূল ফোল্ডারের logs ফোল্ডারে আলাদা লগ ফাইল হিসেবেও সংরক্ষিত হয়। কাজ শেষ হলে তার পাথ দেখানো হয়। Clear Log শুধু উইন্ডো খালি করে। উইন্ডো সর্বশেষ 5000 লাইন রাখে।

এই সেশনে Code Browser বা Gateway Apps থেকে যা কম্পাইল করা হয়েছে, টেবিলে তা তালিকাভুক্ত থাকে: অ্যাপ, তার Python সোর্স, তৈরি হওয়া এক্সিকিউটেবল, Result (Queued, Running, Compiled, Failed অথবা Cancelled) এবং কোথায় প্রকাশ করা হয়েছে। কাজ চলার সঙ্গে সঙ্গে সারিগুলো বদলায় এবং আপনার সাজানোর ক্রম বজায় থাকে।
Test Selected PY Python সোর্স চালায় এবং Test Selected EXE Temp Compile থেকে কম্পাইল করা প্রোগ্রাম চালায়। এখানে নির্বাচিত সারিগুলো ব্যবহার করা হয়; কোনো সারি নির্বাচিত না থাকলে সর্বশেষ ব্যবহৃত তালিকায় নির্বাচিত ফাইলগুলো ব্যবহার করা হয়। Open Temp Compile ফাইল ম্যানেজারে বিল্ড ফোল্ডার দেখায় এবং Clear Results টেবিল খালি করে। CSV ও HTML বোতাম টেবিল রপ্তানি করে।
প্রথমে exe পরীক্ষা করুন, তারপর প্রকাশ করুন। দুটি প্রকাশ বোতামই শুধু Compiled দেখানো নির্বাচিত সারিগুলোর ওপর কাজ করে। প্রতিটি বোতাম প্রথমে অ্যাপটিকে Compile Apps-এর নিজস্ব ফোল্ডারে exe এবং settings json-সহ কপি করে। Python ফাইলের পাশের settings json কেবল তখনই কপি হয়, যখন অ্যাপটির সেখানে আগে থেকে সেটি নেই; তাই আপনার পরিবর্তন করা সেটিংস কখনো ওভাররাইট হয় না। অন্য ভাষার সহায়তা ফাইল (name.fr.txt ইত্যাদি) একইভাবে exe-এর পাশে কপি হয়। এগুলো ইচ্ছাকৃতভাবে বাইরের ফাইল, যাতে আবার কম্পাইল না করেই ভাষা যোগ বা সংশোধন করা যায়। ইংরেজি সহায়তা ফাইল কপি হয় না, কারণ এটি exe-এর মধ্যে যুক্ত। এরপর:
Update Gateway gateway.json-এ Python ফাইলের জায়গায় কপি করা exe-এর লিংক বসায়। প্রথমে অনুমতি চায়, gateway.json.bak নামে ব্যাকআপ রাখে এবং অ্যাপটি ফাইলে না থাকলে নতুন এন্ট্রি যোগ করে। Python সোর্সটি source_py নামে এন্ট্রিতে রাখা হয়, তাই অ্যাপটি Gateway Apps-এ থাকে এবং আবার কম্পাইল করা যায়।
Add Start Menu আপনার Start Menu-তে কপি করা exe-এর শর্টকাট যোগ করে। শর্টকাটের নাম অ্যাপের নামে হয় (gateway এন্ট্রির app_name, অথবা Code Browser থেকে আসা ফাইলের নাম) এবং Config-এ নির্ধারিত Start Menu ফোল্ডারে রাখা হয়। শর্টকাট আগে থেকে থাকলে সেটি আপডেট করা হয়।
নতুন বিল্ডের পর একই এন্ট্রি আপডেট করতে এগুলো আবার চালান। কপি ব্যর্থ হলে চলমান অ্যাপ বন্ধ করে আবার চেষ্টা করুন। কম্পাইলের মতো এগুলোও কাজ হিসেবে চলে, তাই চলমান কম্পাইলের পরে সারিতে অপেক্ষা করে। Open Compile Apps, Compile Apps ফোল্ডার খোলে।

Config প্রোগ্রামের কাজের ধাপ অনুসারে ওপর থেকে নিচে সাজানো। নিচের Save Settings সব সেটিংস settings ফাইলে লেখে এবং কোথায় সংরক্ষিত হয়েছে তা দেখায়।
Code Browser (সাধারণ ফোল্ডার): Default folder হলো Code Browser প্রথমে যে ফোল্ডার খোলে। Browse... সেটি নির্বাচন করে এবং Use Current বর্তমানে Code Browser-এ দেখানো ফোল্ডার ব্যবহার করে। Recent folders ব্যবহৃত ফোল্ডারগুলো নতুন থেকে পুরোনো ক্রমে দেখায় এবং সর্বশেষ 15টি রাখে। Code Browser-এ খোলা প্রতিটি ফোল্ডার স্বয়ংক্রিয়ভাবে যুক্ত হয়। একটি ফোল্ডার লিখুন বা বেছে নিন; তালিকায় যোগ করতে Add, সরাতে Remove অথবা Code Browser-এ দেখাতে Open চাপুন।
Gateway (সোর্স তালিকা): Gateway Apps-এর অ্যাপগুলো তালিকাভুক্ত করা ফাইল। Browse... এটি নির্বাচন করে, Default প্রোগ্রামের ফোল্ডারের gateway.json-এ ফেরে এবং Reload ফাইলটি আবার পড়ে। এখানে কিছু কম্পাইল বা কপি করা হয় না।
Temp Compile: Output root হলো build, dist ও spec ফোল্ডার এবং কাজের লগ রাখার স্থান; প্রতিটি অ্যাপের জন্য আলাদা ফোল্ডার থাকে। এগুলো পরীক্ষার অস্থায়ী ফাইল, সম্পূর্ণ অ্যাপ নয়। Python (PyInstaller) হলো PyInstaller ও Python পরীক্ষা চালানোর জন্য ব্যবহৃত python.exe। এই প্রোগ্রাম নিজেই exe হলে শুধু তখন এটি দরকার, কারণ exe PyInstaller চালাতে পারে না। PATH-এ পাওয়া Python ব্যবহার করতে এটি খালি রাখুন।
Compile Apps: Apps folder হলো সম্পূর্ণ অ্যাপ রাখার স্থান; প্রতিটি অ্যাপের নিজস্ব ফোল্ডারে exe এবং settings json থাকে। Start Menu শর্টকাট ও নতুন gateway এন্ট্রি এই কপির দিকে নির্দেশ করে। Start Menu folder হলো শর্টকাট যোগ করার ফোল্ডারের নাম। Browse... দিয়ে নতুন Apps ফোল্ডার বেছে নিলে settings ফাইলটিও সেখানে রাখতে চান কি না জিজ্ঞাসা করা হবে।
এই প্রোগ্রাম নিজেই exe হলে ইংরেজি সহায়তা এর মধ্যে যুক্ত থাকে। প্রথমবার চালু হলে সম্পাদনার জন্য exe-এর পাশে একটি কপি রাখা হয়; এটি কখনো প্রতিস্থাপিত হয় না এবং মুছে ফেললে ভেতরে থাকা লেখা আবার দেখা যায়। অন্য ভাষার সহায়তা exe-এর পাশে সাধারণ ফাইল হিসেবে থাকে।
Settings file: এই প্রোগ্রামের নিজস্ব সেটিংস (python_compiler.json) কোথায় রাখা হয় তা দেখায়। শুরুতে এগুলো প্রোগ্রামের একই ফোল্ডারে থাকে (exe অথবা এই script), কখনো অস্থায়ী ফোল্ডারে নয়। Browse... অন্য ফোল্ডার বেছে নেয়, Use Apps Folder সেটিংস Compile Apps ফোল্ডারে সরায় এবং Default সেগুলো প্রোগ্রামের ফোল্ডারে ফিরিয়ে আনে। বর্তমান সেটিংস নতুন স্থানে সংরক্ষিত হয় এবং প্রোগ্রামের ফোল্ডারে একটি ছোট নোট থাকে, যেখানে অবস্থান লেখা থাকে, যাতে পরেরবার চালু হলে প্রোগ্রাম সেটিংস খুঁজে পায়। পুরোনো কপি আগের জায়গায় থাকে। শুরুতে settings ফোল্ডার পাওয়া না গেলে (যেমন নেটওয়ার্ক ড্রাইভ), ডিফল্ট সেটিংস ব্যবহার করা হয় এবং নোটটি রাখা হয়।
রং, ঘনত্ব এবং উইন্ডোর আকার UI Choices-এ রয়েছে।

রঙের থিম, ঘনত্ব এবং উইন্ডোর আকার বেছে নিন। Use Current Size বর্তমান উইন্ডোর আকার নেয় এবং Apply + Save আপনার পছন্দ প্রয়োগ ও সংরক্ষণ করে। তালিকার ডোরা আপনার নির্বাচিত থিম অনুসরণ করে। এই সেটিংস অ্যাপের চেহারা নিয়ন্ত্রণ করে। ফোল্ডার ও বিকল্পগুলো Config-এ থাকে।

নিবন্ধিত অ্যাপ্লিকেশন, ফাইল, ফোল্ডার এবং লিংক খুলতে শেয়ার করা launcher ব্যবহার করুন। এটি প্রোগ্রামের ফোল্ডারের gateway_cards.json ফাইলে কার্ডগুলো রাখে। Gateway, Gateway Apps তালিকা সরবরাহকারী gateway ফাইল থেকে আলাদা।

Python Compiler convierte programas Python en programas de Windows con PyInstaller, los prueba y los publica. Sigue este flujo:

Code Browser o Gateway Apps (el código fuente Python) > Temp Compile (los archivos de compilación y prueba) > Outputs (prueba y luego publicación) > Compile Apps (las aplicaciones terminadas, el menú Inicio y la nueva entrada de Gateway).

Code Browser compila archivos Python desde cualquier carpeta. Gateway Apps compila las aplicaciones incluidas en el archivo gateway (gateway.json). Ambas listas permiten leer el código con el botón derecho. Outputs prueba lo que se ha creado y lo publica. Log registra todo lo que sucede. La línea inferior de la ventana siempre muestra la última acción y su resultado, el trabajo en ejecución y los botones Cancel.

La compilación es un trabajo por lotes que se ejecuta en segundo plano, por lo que la ventana sigue estando disponible. Si pulsa Compile mientras hay un trabajo en ejecución, el nuevo trabajo se añade a la cola.

Comience en Code Browser: elija una carpeta, seleccione un archivo Python y pulse Compile Selected. Después abra Outputs para probar el resultado y publíquelo cuando esté satisfecho. Configure sus carpetas en Config. Haga clic en cualquier título de Notes para abrir la pestaña correspondiente.

Compile archivos Python directamente desde una carpeta. Folder muestra la carpeta actual. Escriba una ruta o elija una de sus carpetas recientes en la lista desplegable. Browse... elige una carpeta, Up abre la carpeta superior, Default vuelve a la carpeta predeterminada configurada en Config y Refresh vuelve a leer la carpeta. Solo se muestran los archivos que están directamente dentro de la carpeta. Cada carpeta que abra se añade automáticamente a la lista de recientes.

Compile Selected compila los archivos seleccionados. Compile All Shown compila todos los archivos de la lista; por eso, use primero Search para reducir la lista. One File empaqueta cada programa en un único archivo exe, Windowed oculta la ventana de consola, Clean elimina primero los archivos de compilación antiguos de PyInstaller y No UPX omite el paso de compresión UPX, que es lento y a menudo solo produce advertencias. Estas cuatro opciones también se comparten con Gateway Apps. Solo se compilan archivos .py y .pyw. Cada pulsación crea un trabajo: si hay otro trabajo en ejecución, espera su turno. Cancel Job detiene el trabajo en ejecución y Cancel All también vacía la cola.

Escriba en Search para mostrar solo los archivos cuyos nombres contienen ese texto; X borra el cuadro. La casilla .py / .pyw only oculta otros tipos de archivos. La lista muestra el nombre del archivo, las fechas de creación y última modificación, y su tamaño. El archivo modificado más recientemente aparece arriba; haga clic en el título de una columna para cambiar el orden.

Si junto a un archivo Python hay un archivo de ayuda en inglés (name.en.txt, o el nombre sin el prefijo cpc_), este se incorpora al exe, por lo que la pestaña Notes del programa compilado siempre contiene el texto en inglés. El registro de compilación muestra "Embedding help".

Haga clic con el botón derecho en un archivo para ver el código. Se abre una ventana con el código y los números de línea. Copy All copia todo el texto, Open File abre el archivo en su editor habitual y Close (o la tecla Esc) cierra la ventana. Si un archivo supera 1 MB, solo se muestra su primer megabyte; los archivos binarios no se muestran. La vista previa no puede modificar el archivo.

Los botones CSV y HTML de la parte superior derecha exportan los archivos mostrados, en el orden visible. Nunca se sobrescribe un archivo; si el nombre ya existe, se añaden la fecha y la hora al nuevo nombre.

Compile las aplicaciones incluidas en el archivo gateway (gateway.json). Solo se muestran archivos Python (.py y .pyw). Reload Gateway vuelve a leer el archivo y Project limita la lista a un proyecto o a All.

Seleccione una o más aplicaciones y pulse Compile Selected. Compile All Shown compila todas las aplicaciones que aparecen actualmente en la lista. One File, Windowed, Clean y No UPX funcionan igual que en Code Browser. Cada compilación se guarda en su propia carpeta dentro de la raíz de salida Temp Compile configurada en Config.

Haga clic en el título de una columna para ordenar. Haga clic con el botón derecho en una aplicación para ver su código. Los botones CSV y HTML de la parte superior derecha exportan la lista exactamente como se muestra, incluido el orden elegido.

Registro de todos los trabajos: cuándo se pusieron en cola y cuándo comenzaron, la salida de PyInstaller de cada aplicación (con sangría), cuánto tardó cada aplicación y el resultado. Las líneas se identifican con el número de trabajo, por ejemplo [Job 3 2/5], que significa la segunda de cinco aplicaciones del trabajo 3.

Cada trabajo también se guarda en su propio archivo de registro dentro de la carpeta logs, bajo la raíz de salida Temp Compile; su ruta se muestra cuando termina el trabajo. Clear Log solo vacía la ventana. La ventana conserva las 5000 líneas más recientes.

La tabla enumera lo que ha compilado durante esta sesión, desde Code Browser o Gateway Apps: la aplicación, su código fuente Python, el archivo ejecutable resultante, el resultado (Queued, Running, Compiled, Failed o Cancelled) y dónde se ha publicado. Las filas se actualizan mientras se ejecuta el trabajo y se conserva el orden elegido.

Test Selected PY ejecuta el código fuente Python y Test Selected EXE ejecuta el programa compilado desde Temp Compile. Utilizan las filas seleccionadas aquí; si no hay ninguna seleccionada, utilizan los archivos seleccionados en la última lista que usó. Open Temp Compile muestra la carpeta de compilación en el administrador de archivos y Clear Results vacía la tabla. Los botones CSV y HTML la exportan.

Pruebe primero el exe y después publíquelo. Ambos botones de publicación funcionan con las filas seleccionadas que muestran Compiled. Cada uno copia primero la aplicación a su propia carpeta en Compile Apps, junto con el exe y su archivo json de configuración. El archivo json de configuración solo se copia desde la carpeta del archivo Python si la aplicación todavía no tiene uno allí, por lo que los ajustes que ya haya cambiado nunca se sobrescriben. Los archivos de ayuda en otros idiomas (name.fr.txt, etc.) se copian junto al exe del mismo modo. Son externos deliberadamente, para que se pueda añadir o corregir un idioma sin volver a compilar. El archivo de ayuda en inglés no se copia porque está integrado en el exe. Después:

Update Gateway sustituye el archivo Python en gateway.json por el enlace al exe copiado. Primero pide confirmación, conserva una copia de seguridad llamada gateway.json.bak y añade una entrada si la aplicación no estaba en el archivo. El código fuente Python se conserva en la entrada como source_py, por lo que la aplicación permanece en Gateway Apps y se puede volver a compilar.

Add Start Menu añade al menú Inicio un acceso directo al exe copiado. El acceso directo lleva el nombre de la aplicación (app_name en la entrada de gateway, o el nombre del archivo si procede de Code Browser) y se coloca en la carpeta del menú Inicio configurada en Config. Si el acceso directo ya existe, se actualiza.

Vuelva a ejecutarlos después de una nueva compilación para actualizar las mismas entradas. Si falla la copia, cierre la aplicación en ejecución e inténtelo de nuevo. Se ejecutan como trabajos, igual que la compilación, por lo que esperan detrás de una compilación en curso. Open Compile Apps muestra la carpeta Compile Apps.

Config sigue el flujo del programa, de arriba abajo. Save Settings, en la parte inferior, guarda todos los ajustes en el archivo de configuración e indica dónde se guardaron.

Code Browser (carpetas sin procesar): Default folder es la carpeta que Code Browser abre primero. Browse... la selecciona y Use Current utiliza la carpeta que Code Browser muestra en ese momento. Recent folders enumera las carpetas utilizadas, de la más reciente a la más antigua, y conserva las últimas 15. Cada carpeta que abra en Code Browser se añade automáticamente. Escriba o seleccione una carpeta y pulse Add para añadirla a la lista, Remove para quitarla u Open para mostrarla en Code Browser.

Gateway (lista de código fuente): el archivo que enumera las aplicaciones de Gateway Apps. Browse... lo selecciona, Default vuelve a gateway.json en la carpeta del programa y Reload lo vuelve a leer. Aquí no se compila ni se copia nada.

Temp Compile: Output root es la ubicación de las carpetas build, dist y spec y de los registros de trabajo, con una carpeta por aplicación. Son archivos temporales para las pruebas, no la aplicación terminada. Python (PyInstaller) es el python.exe que se utiliza para ejecutar PyInstaller y las pruebas de Python. Solo se necesita cuando este programa es a su vez un exe, porque un exe no puede ejecutar PyInstaller. Déjelo vacío para usar el Python encontrado en PATH.

Compile Apps: Apps folder es la carpeta donde se guardan las aplicaciones terminadas, cada una en su propia carpeta con su exe y su archivo json de configuración. El acceso directo del menú Inicio y la nueva entrada de gateway apuntan a esta copia. Start Menu folder es el nombre de la carpeta donde se añaden los accesos directos. Cuando elija una nueva carpeta Apps con Browse..., se le preguntará si también desea conservar allí el archivo de configuración.

Cuando este programa es un exe, la ayuda en inglés está integrada. En el primer inicio se coloca una copia junto al exe para que pueda editarse; nunca se sustituye y, si se elimina, vuelve a aparecer el texto integrado. La ayuda en otros idiomas es un archivo normal junto al exe.

Settings file: muestra dónde se guarda la configuración propia de este programa (python_compiler.json). Se guarda inicialmente en la misma carpeta que el programa (el exe o este script), nunca en una carpeta temporal. Browse... elige otra carpeta, Use Apps Folder la traslada a la carpeta Compile Apps y Default la devuelve a la carpeta del programa. Los ajustes actuales se guardan en la nueva ubicación y la carpeta del programa conserva una pequeña nota que indica dónde están, para que el programa pueda encontrarlos en el siguiente inicio. La copia antigua permanece donde estaba. Si la carpeta de configuración no está disponible al iniciar (por ejemplo, una unidad de red), se utilizan los ajustes predeterminados y se conserva la nota.

Los colores, la densidad y el tamaño de la ventana están en UI Choices.

Elija el tema de color, la densidad y el tamaño de la ventana. Use Current Size toma el tamaño actual de la ventana y Apply + Save aplica y guarda sus opciones. Las franjas de la lista siguen el tema elegido. Estos ajustes controlan el aspecto de la aplicación. Las carpetas y las opciones se configuran en Config.

Utilice el lanzador compartido para abrir aplicaciones, archivos, carpetas y enlaces registrados. Guarda sus tarjetas en gateway_cards.json, en la carpeta del programa. Gateway es independiente del archivo gateway que proporciona la lista de Gateway Apps.

Python Compiler transforme les programmes Python en programmes Windows avec PyInstaller, les teste et les publie. Il suit ce processus :

Code Browser ou Gateway Apps (le code source Python) > Temp Compile (les fichiers de compilation et de test) > Outputs (test, puis publication) > Compile Apps (les applications terminées, le menu Démarrer et la nouvelle entrée Gateway).

Code Browser compile les fichiers Python de n’importe quel dossier. Gateway Apps compile les applications répertoriées dans votre fichier gateway (gateway.json). Les deux listes permettent de lire le code par clic droit. Outputs teste ce qui a été créé et le publie. Log enregistre tout ce qui se passe. La ligne au bas de la fenêtre affiche toujours la dernière action et son résultat, la tâche en cours et les boutons Cancel.

La compilation est une tâche par lots exécutée en arrière-plan ; la fenêtre reste donc utilisable. Appuyez de nouveau sur Compile pendant qu’une tâche est en cours : la nouvelle tâche rejoint la file d’attente.

Commencez dans Code Browser : choisissez un dossier, sélectionnez un fichier Python et appuyez sur Compile Selected. Ouvrez ensuite Outputs pour essayer le résultat, puis publiez-le lorsque vous en êtes satisfait. Définissez vos dossiers dans Config. Cliquez sur n’importe quel titre Notes pour ouvrir l’onglet correspondant.

Compilez des fichiers Python directement depuis un dossier. Folder indique le dossier actuel. Saisissez un chemin ou choisissez l’un de vos dossiers récents dans la liste déroulante. Browse... choisit un dossier, Up ouvre son dossier parent, Default revient au dossier par défaut défini dans Config et Refresh relit le dossier. Seuls les fichiers directement présents dans le dossier sont affichés. Chaque dossier ouvert est automatiquement ajouté à la liste récente.

Compile Selected compile les fichiers sélectionnés. Compile All Shown compile tous les fichiers de la liste ; utilisez donc d’abord Search pour réduire la liste. One File regroupe chaque programme dans un seul fichier exe, Windowed masque la fenêtre de console, Clean supprime d’abord les anciens fichiers de compilation de PyInstaller et No UPX ignore l’étape de compression UPX, qui est lente et ne produit souvent que des avertissements. Ces quatre options sont également partagées avec Gateway Apps. Seuls les fichiers .py et .pyw sont compilés. Chaque activation crée une tâche : si une autre tâche est en cours, elle attend son tour. Cancel Job arrête la tâche en cours et Cancel All vide également la file d’attente.

Saisissez du texte dans Search pour n’afficher que les fichiers dont le nom contient ce texte ; X efface le champ. La case .py / .pyw only masque les autres types de fichiers. La liste affiche le nom du fichier, ses dates de création et de dernière modification, ainsi que sa taille. Le fichier modifié le plus récemment apparaît en haut ; cliquez sur un titre de colonne pour modifier le tri.

Si un fichier d’aide en anglais se trouve à côté d’un fichier Python (name.en.txt, ou le nom sans le préfixe cpc_), il est intégré au fichier exe. L’onglet Notes du programme compilé contient donc toujours son texte anglais. Le journal de compilation affiche « Embedding help ».

Cliquez avec le bouton droit sur un fichier pour afficher son code. Une fenêtre s’ouvre avec le code et les numéros de ligne. Copy All copie tout le texte, Open File ouvre le fichier dans votre éditeur habituel et Close (ou la touche Esc) ferme la fenêtre. Pour un fichier de plus de 1 Mo, seul le premier mégaoctet est affiché ; les fichiers binaires ne sont pas affichés. L’aperçu ne peut pas modifier le fichier.

Les boutons CSV et HTML en haut à droite exportent les fichiers affichés, dans l’ordre présenté. Un fichier n’est jamais écrasé ; si le nom existe déjà, la date et l’heure sont ajoutées au nouveau nom.

Compilez les applications répertoriées dans votre fichier gateway (gateway.json). Seuls les fichiers Python (.py et .pyw) sont affichés. Reload Gateway relit le fichier et Project limite la liste à un seul projet ou à All.

Sélectionnez une ou plusieurs applications, puis appuyez sur Compile Selected. Compile All Shown compile toutes les applications actuellement affichées dans la liste. One File, Windowed, Clean et No UPX fonctionnent comme dans Code Browser. Chaque compilation est enregistrée dans son propre dossier sous le répertoire racine de sortie Temp Compile défini dans Config.

Cliquez sur un titre de colonne pour trier. Cliquez avec le bouton droit sur une application pour afficher son code. Les boutons CSV et HTML en haut à droite exportent la liste exactement telle qu’elle apparaît, y compris l’ordre de tri.

Un historique de chaque tâche : son heure de mise en file d’attente et de démarrage, la sortie PyInstaller de chaque application (avec indentation), la durée de chaque application et le résultat. Les lignes portent le numéro de tâche, par exemple [Job 3 2/5], qui signifie la deuxième application sur cinq de la tâche 3.

Chaque tâche est également enregistrée dans son propre fichier journal dans le dossier logs, sous le répertoire racine de sortie Temp Compile ; son chemin s’affiche à la fin de la tâche. Clear Log vide uniquement la fenêtre. La fenêtre conserve les 5000 dernières lignes.

Python Compiler, PyInstaller का उपयोग करके Python प्रोग्राम को Windows प्रोग्राम में बदलता है, उनका परीक्षण करता है और उन्हें प्रकाशित करता है। इसकी प्रक्रिया इस प्रकार है:
Code Browser या Gateway Apps (Python स्रोत कोड) > Temp Compile (बिल्ड और परीक्षण फ़ाइलें) > Outputs (पहले परीक्षण, फिर प्रकाशित करना) > Compile Apps (तैयार ऐप, Start Menu और नई Gateway प्रविष्टि)।
Code Browser किसी भी फ़ोल्डर से Python फ़ाइलों को कंपाइल करता है। Gateway Apps आपकी gateway फ़ाइल (gateway.json) में सूचीबद्ध ऐप को कंपाइल करता है। दोनों सूचियों में राइट-क्लिक करके कोड देखा जा सकता है। Outputs बनी हुई चीज़ का परीक्षण करता है और उसे प्रकाशित करता है। Log हर गतिविधि दर्ज करता है। विंडो के नीचे की पंक्ति हमेशा पिछली कार्रवाई और उसका परिणाम, चल रहे कार्य तथा Cancel बटन दिखाती है।
कंपाइल करना एक बैच कार्य है जो पृष्ठभूमि में चलता है, इसलिए विंडो उपयोग करने योग्य रहती है। कोई कार्य चलते समय फिर से Compile दबाएँ, तो नया कार्य कतार में जुड़ जाता है।
Code Browser से शुरू करें: फ़ोल्डर चुनें, Python फ़ाइल चुनें और Compile Selected दबाएँ। फिर परिणाम आज़माने के लिए Outputs खोलें और संतुष्ट होने पर उसे प्रकाशित करें। Config में अपने फ़ोल्डर निर्धारित करें। Notes के किसी भी शीर्षक पर क्लिक करने से उसका संबंधित टैब खुलता है।

किसी फ़ोल्डर से सीधे Python फ़ाइलें कंपाइल करें। Folder वर्तमान फ़ोल्डर दिखाता है। कोई पथ लिखें या ड्रॉप-डाउन सूची से हाल के फ़ोल्डरों में से चुनें। Browse... फ़ोल्डर चुनता है, Up उसके मूल फ़ोल्डर में जाता है, Default Config में निर्धारित डिफ़ॉल्ट फ़ोल्डर पर लौटता है और Refresh फ़ोल्डर को फिर से पढ़ता है। केवल उसी फ़ोल्डर में सीधे मौजूद फ़ाइलें दिखाई जाती हैं। आपके द्वारा खोला गया हर फ़ोल्डर अपने आप हाल की सूची में जुड़ जाता है।
Compile Selected चुनी हुई फ़ाइलों को कंपाइल करता है। Compile All Shown सूची की हर फ़ाइल को कंपाइल करता है, इसलिए सूची सीमित करने के लिए पहले Search का उपयोग करें। One File प्रत्येक प्रोग्राम को एक exe में पैक करता है, Windowed कंसोल विंडो छिपाता है, Clean पहले PyInstaller की पुरानी बिल्ड फ़ाइलें हटाता है और No UPX UPX संपीड़न चरण छोड़ देता है, जो धीमा है और अक्सर केवल चेतावनियाँ देता है। ये चारों विकल्प Gateway Apps के साथ भी साझा हैं। केवल .py और .pyw फ़ाइलें कंपाइल होती हैं। हर बार दबाने पर एक कार्य बनता है: यदि दूसरा कार्य चल रहा है, तो यह अपनी बारी की प्रतीक्षा करता है। Cancel Job चल रहे कार्य को रोकता है और Cancel All कतार भी खाली करता है।
Search में लिखें ताकि केवल उन फ़ाइलों के नाम दिखें जिनमें वह पाठ है; X बॉक्स खाली करता है। .py / .pyw only बॉक्स अन्य प्रकार की फ़ाइलें छिपाता है। सूची में फ़ाइल का नाम, बनने की तारीख, आखिरी बार बदले जाने की तारीख और आकार दिखता है। सबसे हाल में बदली गई फ़ाइल सबसे ऊपर होती है; क्रम बदलने के लिए किसी कॉलम शीर्षक पर क्लिक करें।
यदि किसी Python फ़ाइल के साथ अंग्रेज़ी सहायता फ़ाइल मौजूद है (name.en.txt, या cpc_ उपसर्ग के बिना वही नाम), तो उसे exe में शामिल किया जाता है। इसलिए कंपाइल किए गए प्रोग्राम के Notes टैब में अंग्रेज़ी पाठ हमेशा उपलब्ध रहता है। कंपाइल लॉग में "Embedding help" दिखता है।
कोड देखने के लिए फ़ाइल पर राइट-क्लिक करें। कोड और पंक्ति संख्याओं वाली विंडो खुलती है। Copy All पूरा पाठ कॉपी करता है, Open File फ़ाइल को आपके सामान्य संपादक में खोलता है और Close (या Esc कुंजी) विंडो बंद करता है। 1 MB से बड़ी फ़ाइल का केवल पहला मेगाबाइट दिखाया जाता है और बाइनरी फ़ाइलें नहीं दिखाई जातीं। पूर्वावलोकन फ़ाइल को बदल नहीं सकता।
ऊपर दाईं ओर के CSV और HTML बटन दिखाई गई फ़ाइलों को उसी क्रम में निर्यात करते हैं। किसी फ़ाइल को कभी ओवरराइट नहीं किया जाता; यदि नाम पहले से मौजूद है, तो नए नाम में तारीख और समय जोड़ दिए जाते हैं।

अपनी gateway फ़ाइल (gateway.json) में सूचीबद्ध ऐप कंपाइल करें। केवल Python फ़ाइलें (.py और .pyw) दिखाई जाती हैं। Reload Gateway फ़ाइल को फिर से पढ़ता है और Project सूची को एक प्रोजेक्ट या All तक सीमित करता है।
एक या अधिक ऐप चुनें, फिर Compile Selected दबाएँ। Compile All Shown सूची में वर्तमान में दिखाई देने वाले सभी ऐप कंपाइल करता है। One File, Windowed, Clean और No UPX, Code Browser की तरह काम करते हैं। हर कंपाइल को Config में निर्धारित Temp Compile आउटपुट रूट के अंतर्गत अपने अलग फ़ोल्डर में रखा जाता है।
क्रम बदलने के लिए कॉलम शीर्षक पर क्लिक करें। कोड देखने के लिए किसी ऐप पर राइट-क्लिक करें। ऊपर दाईं ओर के CSV और HTML बटन सूची को ठीक उसी तरह निर्यात करते हैं जैसे वह दिखाई देती है, जिसमें क्रम भी शामिल है।

हर कार्य का रिकॉर्ड: उसे कतार में कब रखा गया और कब शुरू हुआ, हर ऐप का PyInstaller आउटपुट (इंडेंट सहित), हर ऐप में लगा समय और परिणाम। पंक्तियों पर कार्य संख्या अंकित होती है, जैसे [Job 3 2/5], जिसका अर्थ है कार्य 3 में पाँच ऐप में से दूसरा ऐप।
हर कार्य Temp Compile आउटपुट रूट के अंतर्गत logs फ़ोल्डर में अपनी अलग लॉग फ़ाइल के रूप में भी सहेजा जाता है। कार्य समाप्त होने पर उसका पथ दिखाया जाता है। Clear Log केवल विंडो खाली करता है। विंडो नवीनतम 5000 पंक्तियाँ रखती है।

तालिका इस सत्र में Code Browser या Gateway Apps से कंपाइल की गई चीज़ें दिखाती है: ऐप, उसका Python स्रोत, बनी हुई निष्पादन फ़ाइल, Result (Queued, Running, Compiled, Failed या Cancelled), और उसे कहाँ प्रकाशित किया गया। कार्य चलते समय पंक्तियाँ बदलती हैं और चुना गया क्रम बना रहता है।
Test Selected PY Python स्रोत चलाता है और Test Selected EXE Temp Compile से कंपाइल किया गया प्रोग्राम चलाता है। ये यहाँ चुनी गई पंक्तियों का उपयोग करते हैं; यदि कोई पंक्ति नहीं चुनी गई है, तो पिछली बार उपयोग की गई सूची में चुनी गई फ़ाइलें इस्तेमाल होती हैं। Open Temp Compile फ़ाइल प्रबंधक में बिल्ड फ़ोल्डर दिखाता है और Clear Results तालिका खाली करता है। CSV और HTML बटन इसे निर्यात करते हैं।
पहले exe का परीक्षण करें, फिर उसे प्रकाशित करें। दोनों प्रकाशन बटन केवल उन चुनी हुई पंक्तियों पर काम करते हैं जिनका परिणाम Compiled है। हर बटन पहले ऐप को Compile Apps में उसके अपने फ़ोल्डर में exe और settings json के साथ कॉपी करता है। Python फ़ाइल के पास से settings json तभी कॉपी किया जाता है जब ऐप के पास वहाँ पहले से ऐसा फ़ाइल न हो; इसलिए आपके बदले हुए सेटिंग कभी ओवरराइट नहीं होते। अन्य भाषाओं की सहायता फ़ाइलें (name.fr.txt आदि) भी इसी तरह exe के पास कॉपी की जाती हैं। इन्हें जानबूझकर बाहरी रखा गया है ताकि दोबारा कंपाइल किए बिना भाषा जोड़ी या सुधारी जा सके। अंग्रेज़ी सहायता फ़ाइल कॉपी नहीं होती क्योंकि वह exe में शामिल है। इसके बाद:
Update Gateway, gateway.json में Python फ़ाइल को कॉपी किए गए exe के लिंक से बदलता है। पहले पुष्टि माँगी जाती है, gateway.json.bak नाम का बैकअप रखा जाता है और यदि ऐप फ़ाइल में नहीं था तो नई प्रविष्टि जोड़ी जाती है। Python स्रोत को source_py के रूप में प्रविष्टि में रखा जाता है, इसलिए ऐप Gateway Apps में बना रहता है और फिर से कंपाइल किया जा सकता है।
Add Start Menu, Start Menu में कॉपी किए गए exe का शॉर्टकट जोड़ता है। शॉर्टकट का नाम ऐप के नाम पर होता है (gateway प्रविष्टि में app_name, या Code Browser से आई फ़ाइल का नाम) और इसे Config में निर्धारित Start Menu फ़ोल्डर में रखा जाता है। यदि शॉर्टकट पहले से मौजूद है, तो उसे अपडेट किया जाता है।
नई बिल्ड के बाद इन्हें फिर चलाएँ ताकि वही प्रविष्टियाँ अपडेट हो जाएँ। कॉपी विफल होने पर चल रहे ऐप को बंद करके फिर प्रयास करें। ये कंपाइल की तरह कार्य के रूप में चलते हैं, इसलिए चल रहे कंपाइल के पीछे कतार में लगते हैं। Open Compile Apps, Compile Apps फ़ोल्डर खोलता है।

Config प्रोग्राम के प्रवाह का ऊपर से नीचे तक अनुसरण करता है। नीचे मौजूद Save Settings सभी सेटिंग को settings फ़ाइल में लिखता है और बताता है कि वे कहाँ सहेजी गईं।
Code Browser (सामान्य फ़ोल्डर): Default folder वह फ़ोल्डर है जिसे Code Browser सबसे पहले खोलता है। Browse... उसे चुनता है और Use Current वह फ़ोल्डर उपयोग करता है जो Code Browser अभी दिखा रहा है। Recent folders आपके उपयोग किए गए फ़ोल्डरों को नवीनतम पहले क्रम में दिखाता है और अंतिम 15 रखता है। Code Browser में खोला गया हर फ़ोल्डर अपने आप जुड़ जाता है। कोई फ़ोल्डर लिखें या चुनें और सूची में जोड़ने के लिए Add, हटाने के लिए Remove या Code Browser में दिखाने के लिए Open दबाएँ।
Gateway (स्रोत सूची): वह फ़ाइल जो Gateway Apps के ऐप सूचीबद्ध करती है। Browse... उसे चुनता है, Default प्रोग्राम के फ़ोल्डर में gateway.json पर लौटता है और Reload उसे फिर से पढ़ता है। यहाँ कुछ भी कंपाइल या कॉपी नहीं होता।
Temp Compile: Output root वह स्थान है जहाँ build, dist और spec फ़ोल्डर तथा कार्य लॉग रखे जाते हैं; हर ऐप का अपना फ़ोल्डर होता है। ये परीक्षण के लिए अस्थायी फ़ाइलें हैं, तैयार ऐप नहीं। Python (PyInstaller) वह python.exe है जिसका उपयोग PyInstaller और Python परीक्षण चलाने के लिए होता है। इसकी आवश्यकता केवल तब होती है जब यह प्रोग्राम स्वयं exe हो, क्योंकि exe PyInstaller नहीं चला सकता। PATH में मिला Python उपयोग करने के लिए इसे खाली छोड़ें।
Compile Apps: Apps folder वह स्थान है जहाँ तैयार ऐप रखे जाते हैं; हर ऐप अपने फ़ोल्डर में exe और settings json के साथ रहता है। Start Menu शॉर्टकट और नई gateway प्रविष्टि इसी कॉपी की ओर संकेत करते हैं। Start Menu folder उस फ़ोल्डर का नाम है जहाँ शॉर्टकट जोड़े जाते हैं। Browse... से नया Apps फ़ोल्डर चुनने पर पूछा जाता है कि settings फ़ाइल भी वहाँ रखनी है या नहीं।
जब यह प्रोग्राम स्वयं exe होता है, तो इसकी अंग्रेज़ी सहायता उसमें शामिल होती है। पहली बार शुरू होने पर संपादन के लिए exe के पास उसकी एक प्रति रखी जाती है; इसे कभी बदला नहीं जाता और इसे हटाने पर शामिल मूल पाठ फिर दिखाई देता है। अन्य भाषाओं की सहायता exe के पास सामान्य फ़ाइल के रूप में रहती है।
Settings file: यह दिखाती है कि इस प्रोग्राम की अपनी सेटिंग (python_compiler.json) कहाँ रखी जाती हैं। शुरुआत में वे प्रोग्राम के उसी फ़ोल्डर में होती हैं जहाँ exe या यह script है; वे कभी अस्थायी फ़ोल्डर में नहीं रखी जातीं। Browse... दूसरा फ़ोल्डर चुनता है, Use Apps Folder सेटिंग्स Compile Apps फ़ोल्डर में ले जाता है और Default उन्हें प्रोग्राम फ़ोल्डर में वापस लाता है। वर्तमान सेटिंग नई जगह सहेजी जाती हैं और प्रोग्राम फ़ोल्डर में एक छोटा नोट रहता है जो उनका स्थान बताता है, ताकि अगली बार शुरू होने पर प्रोग्राम उन्हें ढूँढ़ सके। पुरानी प्रति वहीं रहती है। यदि शुरू होते समय settings फ़ोल्डर उपलब्ध न हो (उदाहरण के लिए नेटवर्क ड्राइव), तो डिफ़ॉल्ट सेटिंग उपयोग होती हैं और नोट बना रहता है।
रंग, घनत्व और विंडो का आकार UI Choices में हैं।

रंग थीम, घनत्व और विंडो का आकार चुनें। Use Current Size विंडो का वर्तमान आकार लेता है और Apply + Save आपके विकल्प लागू करके सहेजता है। सूची की धारियाँ चुनी गई थीम के अनुसार होती हैं। ये सेटिंग ऐप का रूप नियंत्रित करती हैं। फ़ोल्डर और विकल्प Config में निर्धारित होते हैं।

पंजीकृत एप्लिकेशन, फ़ाइलें, फ़ोल्डर और लिंक खोलने के लिए साझा लॉन्चर का उपयोग करें। यह अपने कार्ड प्रोग्राम फ़ोल्डर में gateway_cards.json में रखता है। Gateway, Gateway Apps सूची उपलब्ध कराने वाली gateway फ़ाइल से अलग है।

Python Compiler transforma programas Python em programas do Windows com o PyInstaller, testa-os e publica-os. Segue este fluxo:

Code Browser ou Gateway Apps (o código-fonte Python) > Temp Compile (os ficheiros de compilação e teste) > Outputs (testar e depois publicar) > Compile Apps (as aplicações concluídas, o menu Iniciar e a nova entrada do Gateway).

Code Browser compila ficheiros Python de qualquer pasta. Gateway Apps compila as aplicações listadas no ficheiro gateway (gateway.json). Ambas as listas permitem consultar o código com o botão direito do rato. Outputs testa o que foi criado e publica-o. Log regista tudo o que acontece. A linha na parte inferior da janela mostra sempre a última ação e o respetivo resultado, a tarefa em execução e os botões Cancel.

A compilação é uma tarefa em lote executada em segundo plano, pelo que a janela continua utilizável. Prima Compile novamente enquanto uma tarefa está em execução e a nova tarefa entra na fila.

Comece em Code Browser: escolha uma pasta, selecione um ficheiro Python e prima Compile Selected. Em seguida, abra Outputs para experimentar o resultado e publique-o quando estiver satisfeito. Defina as pastas em Config. Clique em qualquer título de Notes para abrir o separador correspondente.

Compile ficheiros Python diretamente a partir de uma pasta. Folder mostra a pasta atual. Introduza um caminho ou escolha uma das pastas recentes na lista pendente. Browse... escolhe uma pasta, Up abre a pasta principal, Default regressa à pasta predefinida definida em Config e Refresh volta a ler a pasta. Apenas são apresentados os ficheiros diretamente dentro da pasta. Cada pasta aberta é automaticamente adicionada à lista de recentes.

Compile Selected compila os ficheiros selecionados. Compile All Shown compila todos os ficheiros da lista; por isso, utilize primeiro Search para restringir a lista. One File empacota cada programa num único ficheiro exe, Windowed oculta a janela da consola, Clean remove primeiro os ficheiros de compilação antigos do PyInstaller e No UPX ignora a etapa de compressão UPX, que é lenta e muitas vezes apenas produz avisos. Estas quatro opções também são partilhadas com Gateway Apps. Apenas são compilados ficheiros .py e .pyw. Cada pressão cria uma tarefa: se outra tarefa estiver em execução, aguarda a sua vez. Cancel Job interrompe a tarefa em execução e Cancel All também limpa a fila.

Introduza texto em Search para mostrar apenas os ficheiros cujos nomes contêm esse texto; X limpa a caixa. A opção .py / .pyw only oculta outros tipos de ficheiros. A lista mostra o nome do ficheiro, as datas de criação e da última modificação e o tamanho. O ficheiro alterado mais recentemente aparece no topo; clique no título de uma coluna para alterar a ordenação.

Se existir um ficheiro de ajuda em inglês junto de um ficheiro Python (name.en.txt, ou o nome sem o prefixo cpc_), esse ficheiro é incorporado no exe, pelo que o separador Notes do programa compilado contém sempre o texto em inglês. O registo de compilação mostra "Embedding help".

Clique com o botão direito num ficheiro para ver o código. Abre-se uma janela com o código e os números das linhas. Copy All copia todo o texto, Open File abre o ficheiro no editor habitual e Close (ou a tecla Esc) fecha a janela. Um ficheiro com mais de 1 MB mostra apenas o primeiro megabyte; os ficheiros binários não são apresentados. A pré-visualização não pode alterar o ficheiro.

Os botões CSV e HTML no canto superior direito exportam os ficheiros apresentados, pela ordem mostrada. Um ficheiro nunca é substituído; se o nome já existir, a data e a hora são acrescentadas ao novo nome.

Compile as aplicações listadas no ficheiro gateway (gateway.json). Apenas são apresentados ficheiros Python (.py e .pyw). Reload Gateway volta a ler o ficheiro e Project limita a lista a um projeto ou a All.

Selecione uma ou mais aplicações e prima Compile Selected. Compile All Shown compila todas as aplicações atualmente apresentadas na lista. One File, Windowed, Clean e No UPX funcionam como em Code Browser. Cada compilação é guardada na sua própria pasta, dentro da raiz de saída Temp Compile definida em Config.

Clique no título de uma coluna para ordenar. Clique com o botão direito numa aplicação para ver o respetivo código. Os botões CSV e HTML no canto superior direito exportam a lista exatamente como é apresentada, incluindo a ordem de classificação.

Registo de todas as tarefas: quando foram colocadas na fila e iniciadas, a saída do PyInstaller de cada aplicação (com avanço), o tempo que cada aplicação demorou e o resultado. As linhas são identificadas pelo número da tarefa, como [Job 3 2/5], que significa a segunda de cinco aplicações na tarefa 3.

Cada tarefa também é guardada no seu próprio ficheiro de registo na pasta logs, dentro da raiz de saída Temp Compile; o caminho é apresentado quando a tarefa termina. Clear Log limpa apenas a janela. A janela mantém as 5000 linhas mais recentes.

A tabela apresenta o que foi compilado nesta sessão, a partir de Code Browser ou Gateway Apps: a aplicação, o respetivo código-fonte Python, o executável resultante, o resultado (Queued, Running, Compiled, Failed ou Cancelled) e o local onde foi publicado. As linhas são atualizadas durante a execução da tarefa e a ordenação escolhida é mantida.

Test Selected PY executa o código-fonte Python e Test Selected EXE executa o programa compilado a partir de Temp Compile. Utilizam as linhas selecionadas aqui; se nenhuma estiver selecionada, utilizam os ficheiros selecionados na última lista utilizada. Open Temp Compile mostra a pasta de compilação no gestor de ficheiros e Clear Results limpa a tabela. Os botões CSV e HTML exportam-na.

Teste primeiro o exe e depois publique-o. Ambos os botões de publicação funcionam nas linhas selecionadas com o estado Compiled. Cada um copia primeiro a aplicação para a sua própria pasta em Compile Apps, juntamente com o exe e o respetivo ficheiro json de definições. O ficheiro json de definições só é copiado da pasta do ficheiro Python se a aplicação ainda não tiver um nessa localização; assim, as definições que já alterou nunca são substituídas. Os ficheiros de ajuda noutros idiomas (name.fr.txt e assim por diante) são copiados para junto do exe da mesma forma. São externos de propósito, para que possa adicionar ou corrigir um idioma sem voltar a compilar. O ficheiro de ajuda em inglês não é copiado porque está incorporado no exe. Depois:

Update Gateway substitui o ficheiro Python em gateway.json pela ligação ao exe copiado. Primeiro pede confirmação, mantém uma cópia de segurança chamada gateway.json.bak e adiciona uma entrada se a aplicação ainda não estiver no ficheiro. O código-fonte Python é mantido na entrada como source_py, para que a aplicação continue em Gateway Apps e possa ser compilada novamente.

Add Start Menu adiciona ao menu Iniciar um atalho para o exe copiado. O atalho tem o nome da aplicação (app_name na entrada gateway, ou o nome do ficheiro para um ficheiro proveniente de Code Browser) e é colocado na pasta do menu Iniciar definida em Config. Se o atalho já existir, é atualizado.

Execute-os novamente após uma nova compilação para atualizar as mesmas entradas. Se a cópia falhar, feche a aplicação em execução e tente novamente. São executados como tarefas, tal como a compilação, pelo que ficam na fila atrás de uma compilação em curso. Open Compile Apps mostra a pasta Compile Apps.

Config segue o fluxo do programa, de cima para baixo. Save Settings, na parte inferior, grava todas as definições no ficheiro de definições e mostra onde foram guardadas.

Code Browser (pastas diretas): Default folder é a pasta que Code Browser abre primeiro. Browse... escolhe-a e Use Current utiliza a pasta que Code Browser está a mostrar neste momento. Recent folders lista as pastas utilizadas, da mais recente para a mais antiga, e mantém as últimas 15. Todas as pastas abertas em Code Browser são adicionadas automaticamente. Introduza ou escolha uma pasta e prima Add para a adicionar à lista, Remove para a retirar ou Open para a mostrar em Code Browser.

Gateway (lista de origem): o ficheiro que lista as aplicações de Gateway Apps. Browse... escolhe-o, Default regressa a gateway.json na pasta do programa e Reload volta a lê-lo. Aqui não é feita qualquer compilação nem cópia.

Temp Compile: Output root é a localização das pastas build, dist e spec e dos registos das tarefas, com uma pasta por aplicação. São ficheiros temporários para testes, não a aplicação concluída. Python (PyInstaller) é o python.exe utilizado para executar o PyInstaller e os testes Python. Só é necessário quando este programa é, ele próprio, um exe, porque um exe não consegue executar o PyInstaller. Deixe vazio para utilizar o Python encontrado em PATH.

Compile Apps: Apps folder é a pasta onde ficam as aplicações concluídas, cada uma na sua própria pasta com o exe e o ficheiro json de definições. O atalho do menu Iniciar e a nova entrada gateway apontam para esta cópia. Start Menu folder é o nome da pasta onde os atalhos são adicionados. Quando escolhe uma nova pasta Apps com Browse..., é-lhe perguntado se também pretende manter aí o ficheiro de definições.

Quando este programa é, ele próprio, um exe, a ajuda em inglês está incorporada. No primeiro arranque, é colocada uma cópia junto do exe para poder ser editada; nunca é substituída e, se for eliminada, o texto incorporado volta a aparecer. A ajuda noutros idiomas é um ficheiro simples junto do exe.

Settings file: mostra onde são guardadas as definições deste programa (python_compiler.json). Inicialmente ficam na mesma pasta do programa (o exe ou este script), nunca numa pasta temporária. Browse... escolhe outra pasta, Use Apps Folder move-as para a pasta Compile Apps e Default devolve-as à pasta do programa. As definições atuais são guardadas na nova localização e a pasta do programa mantém uma pequena nota que indica onde estão, para que o programa as encontre no arranque seguinte. A cópia antiga permanece onde estava. Se a pasta das definições não estiver disponível no arranque (por exemplo, uma unidade de rede), são utilizadas as definições predefinidas e a nota é mantida.

As cores, a densidade e o tamanho da janela estão em UI Choices.

Escolha o tema de cores, a densidade e o tamanho da janela. Use Current Size utiliza o tamanho atual da janela e Apply + Save aplica e guarda as suas escolhas. As listas seguem o tema escolhido. Estas definições controlam o aspeto da aplicação. As pastas e as opções pertencem a Config.

Utilize o iniciador partilhado para abrir aplicações, ficheiros, pastas e ligações registados. Guarda os seus cartões em gateway_cards.json na pasta do programa. Gateway é separado do ficheiro gateway que fornece a lista Gateway Apps.

Ginagawang Windows programs ng Python Compiler ang mga Python program gamit ang PyInstaller, sinusubukan ang mga ito, at inilalathala. Sinusunod nito ang daloy na ito:

Code Browser o Gateway Apps (ang Python source code) > Temp Compile (mga build at test file) > Outputs (subukan, pagkatapos ay ilathala) > Compile Apps (mga tapos na app, Start Menu, at bagong Gateway entry).

Nagko-compile ang Code Browser ng mga Python file mula sa anumang folder. Kino-compile ng Gateway Apps ang mga app na nakalista sa iyong gateway file (gateway.json). Sa dalawang listahan, maaari mong tingnan ang code sa pamamagitan ng right-click. Sinusubukan ng Outputs ang ginawa at inilalathala ito. Itinatala ng Log ang lahat ng nangyayari. Palaging ipinapakita ng linya sa ibaba ng window ang pinakahuling aksiyon at resulta nito, ang kasalukuyang trabaho, at ang mga Cancel button.

Batch job ang pagko-compile na tumatakbo sa background, kaya magagamit pa rin ang window. Pindutin muli ang Compile habang may tumatakbong trabaho at idaragdag sa pila ang bagong trabaho.

Magsimula sa Code Browser: pumili ng folder, pumili ng Python file, at pindutin ang Compile Selected. Pagkatapos, buksan ang Outputs upang subukan ang resulta at ilathala ito kapag nasiyahan ka na. Itakda ang iyong mga folder sa Config. I-click ang anumang Notes heading upang buksan ang katumbas na tab.

Mag-compile ng mga Python file nang direkta mula sa isang folder. Ipinapakita ng Folder ang kasalukuyang folder. Mag-type ng path o pumili ng isa sa iyong mga kamakailang folder mula sa drop-down list. Pumipili ng folder ang Browse..., binubuksan ng Up ang parent folder nito, ibinabalik ng Default ang default na folder na itinakda sa Config, at muling binabasa ng Refresh ang folder. Ang mga file na direktang nasa folder lamang ang ipinapakita. Awtomatikong idinaragdag sa recent list ang bawat folder na bubuksan mo.

Kino-compile ng Compile Selected ang mga napiling file. Kino-compile ng Compile All Shown ang bawat file sa listahan, kaya gamitin muna ang Search upang paliitin ang listahan. Pinagsasama ng One File ang bawat program sa iisang exe, itinatago ng Windowed ang console window, inaalis muna ng Clean ang mga lumang build file ng PyInstaller, at nilalaktawan ng No UPX ang UPX compression step na mabagal at kadalasan ay mga babala lamang ang nalilikha. Pareho ang apat na pagpipiliang ito sa Gateway Apps. .py at .pyw file lamang ang kino-compile. Bawat pagpindot ay lumilikha ng isang trabaho: kung may ibang trabahong tumatakbo, maghihintay ito ng pagkakataon. Itinitigil ng Cancel Job ang tumatakbong trabaho, at nililinis din ng Cancel All ang pila.

Mag-type sa Search upang ipakita lamang ang mga file na may ganoong teksto sa pangalan; nililinis ng X ang kahon. Itinatago ng .py / .pyw only box ang ibang uri ng file. Ipinapakita ng listahan ang pangalan ng file, petsa ng pagkakagawa at huling pagbabago, at laki nito. Nasa itaas ang pinakahuling binagong file; i-click ang heading ng column upang baguhin ang pagkakasunod-sunod.

Kung may English help file sa tabi ng isang Python file (name.en.txt, o ang pangalan nito na walang cpc_ prefix), isinasama ito sa exe, kaya laging naroon ang English text sa Notes tab ng compiled program. Ipinapakita ng compile log ang "Embedding help".

Mag-right-click sa isang file upang makita ang code. Bubukas ang window na may code at mga numero ng linya. Kinokopya ng Copy All ang buong teksto, binubuksan ng Open File ang file sa karaniwan mong editor, at isinasara ng Close (o Esc key) ang window. Kung lampas 1 MB ang file, unang megabyte lamang nito ang ipinapakita; hindi ipinapakita ang binary file. Hindi mababago ng preview ang file.

Ini-export ng CSV at HTML button sa kanang itaas ang mga ipinapakitang file, ayon sa pagkakasunod ng mga ito. Hindi kailanman ino-overwrite ang isang file; kung ginagamit na ang pangalan, idaragdag ang petsa at oras sa bagong pangalan.

I-compile ang mga app na nakalista sa iyong gateway file (gateway.json). Python file lamang (.py at .pyw) ang ipinapakita. Muling binabasa ng Reload Gateway ang file, at nililimitahan ng Project ang listahan sa isang project o sa All.

Pumili ng isa o higit pang app, pagkatapos ay pindutin ang Compile Selected. Kino-compile ng Compile All Shown ang lahat ng app na kasalukuyang nasa listahan. Gumagana ang One File, Windowed, Clean at No UPX gaya ng sa Code Browser. Isinusulat ang bawat compile sa sarili nitong folder sa ilalim ng Temp Compile output root na itinakda sa Config.

I-click ang heading ng column upang ayusin ang pagkakasunod-sunod. Mag-right-click sa isang app upang makita ang code nito. Ini-export ng CSV at HTML button sa kanang itaas ang listahan nang eksakto sa ipinapakita nitong ayos, kasama ang piniling sort order.

Talaan ng bawat trabaho: kung kailan ito inilagay sa pila at nagsimula, ang PyInstaller output ng bawat app (may indent), gaano katagal ang bawat app, at ang resulta. Minamarkahan ang mga linya ng numero ng trabaho, gaya ng [Job 3 2/5], na nangangahulugang ikalawa sa limang app sa job 3.

Nai-save din ang bawat trabaho bilang sarili nitong log file sa logs folder sa ilalim ng Temp Compile output root, at ipinapakita ang path nito kapag natapos ang trabaho. Window lamang ang nililinis ng Clear Log. Pinananatili ng window ang pinakabagong 5000 linya.

Python Compiler 使用 PyInstaller 将 Python 程序转换为 Windows 程序、进行测试并发布。工作流程如下：
Code Browser 或 Gateway Apps（Python 源代码）> Temp Compile（构建和测试文件）> Outputs（先测试，再发布）> Compile Apps（已完成的应用程序、开始菜单和新的 Gateway 条目）。
Code Browser 可以编译任何文件夹中的 Python 文件。Gateway Apps 编译 gateway 文件（gateway.json）中列出的应用程序。两个列表都可以通过右键单击查看代码。Outputs 测试构建结果并发布。Log 记录所有操作。窗口底部的状态行始终显示最近的操作及其结果、正在运行的任务以及 Cancel 按钮。
编译是一个在后台运行的批处理任务，因此窗口仍可使用。任务运行期间再次按 Compile，新任务就会加入队列。
从 Code Browser 开始：选择文件夹，选择一个 Python 文件，然后按 Compile Selected。接着打开 Outputs 试运行结果，满意后再发布。在 Config 中设置文件夹。单击任意 Notes 标题即可打开对应的选项卡。

直接从文件夹编译 Python 文件。Folder 显示当前文件夹。输入路径，或从下拉列表中选择最近使用的文件夹。Browse... 用于选择文件夹，Up 打开上一级文件夹，Default 返回 Config 中设置的默认文件夹，Refresh 重新读取文件夹。列表只显示该文件夹内的文件，不包括子文件夹中的文件。每个打开过的文件夹都会自动加入最近使用列表。
Compile Selected 编译所选文件。Compile All Shown 编译列表中的所有文件，因此请先使用 Search 缩小列表范围。One File 将每个程序打包成一个 exe 文件；Windowed 隐藏控制台窗口；Clean 先删除 PyInstaller 的旧构建文件；No UPX 跳过 UPX 压缩步骤，该步骤速度较慢，而且通常只会产生警告。这四个选项也适用于 Gateway Apps。只编译 .py 和 .pyw 文件。每次按下按钮都会创建一个任务：如果另一个任务正在运行，新任务就会等待。Cancel Job 停止正在运行的任务；Cancel All 还会清空队列。
在 Search 中输入文字，只显示文件名包含该文字的文件；X 清空输入框。.py / .pyw only 复选框隐藏其他类型的文件。列表显示文件名、创建日期、最后修改日期和大小。最近修改的文件显示在最上方；单击列标题可以更改排序方式。
如果 Python 文件旁边有英文帮助文件（name.en.txt，或不带 cpc_ 前缀的文件名），该文件会嵌入 exe，因此编译后程序的 Notes 选项卡始终包含英文文本。编译日志会显示 "Embedding help"。
右键单击文件即可查看代码。窗口中会显示代码和行号。Copy All 复制全部文本，Open File 使用常用编辑器打开文件，Close（或 Esc 键）关闭窗口。超过 1 MB 的文件只显示前 1 MB；不显示二进制文件。预览功能不会修改文件。
右上角的 CSV 和 HTML 按钮按当前显示顺序导出文件列表。文件不会被覆盖；如果名称已存在，新文件名会附加日期和时间。

编译 gateway 文件（gateway.json）中列出的应用程序。只显示 Python 文件（.py 和 .pyw）。Reload Gateway 重新读取该文件；Project 将列表限制为一个项目，或选择 All。
选择一个或多个应用程序，然后按 Compile Selected。Compile All Shown 编译当前列表中的所有应用程序。One File、Windowed、Clean 和 No UPX 的功能与 Code Browser 中相同。每次编译都会在 Config 中设置的 Temp Compile 输出根目录下创建独立文件夹。
单击列标题进行排序。右键单击应用程序可查看代码。右上角的 CSV 和 HTML 按钮会按照列表当前显示的内容和排序顺序导出列表。

记录每个任务的完整过程：任务进入队列和开始运行的时间、每个应用程序的 PyInstaller 输出（带缩进）、每个应用程序耗费的时间以及结果。每行都标有任务编号，例如 [Job 3 2/5] 表示任务 3 中五个应用程序里的第二个。
每个任务还会单独保存为日志文件，位于 Temp Compile 输出根目录下的 logs 文件夹中。任务结束时会显示日志文件路径。Clear Log 只清空窗口。窗口保留最新的 5000 行。

此表列出本次会话中从 Code Browser 或 Gateway Apps 编译的内容：应用程序、其 Python 源文件、生成的可执行文件、结果（Queued、Running、Compiled、Failed 或 Cancelled）以及发布位置。任务运行时表格行会更新，并保留当前排序方式。
Test Selected PY 运行 Python 源代码；Test Selected EXE 运行 Temp Compile 中编译出的程序。它们使用此处选中的行；如果没有选中任何行，则使用最近一次所用列表中选中的文件。Open Temp Compile 在文件管理器中打开构建文件夹，Clear Results 清空表格。CSV 和 HTML 按钮可导出表格。
先测试 exe，再发布。两个发布按钮都只处理结果为 Compiled 的选中行。每个按钮都会先将应用程序复制到 Compile Apps 中自己的文件夹，并复制 exe 和设置 json 文件。只有当应用程序旁边还没有设置 json 文件时，才会从 Python 文件旁边复制该文件，因此已经修改过的设置不会被覆盖。其他语言的帮助文件（name.fr.txt 等）也会以相同方式复制到 exe 旁边。这些文件特意保持为外部文件，因此无需重新编译即可添加或修正语言。英文帮助文件不会复制，因为它已嵌入 exe。然后：
Update Gateway 将 gateway.json 中的 Python 文件替换为指向已复制 exe 的链接。操作前会请求确认，保留名为 gateway.json.bak 的备份；如果文件中还没有该应用程序，则添加一个条目。Python 源代码以 source_py 的名称保留在条目中，因此应用程序仍会显示在 Gateway Apps 中，并可再次编译。
Add Start Menu 会在开始菜单中为已复制的 exe 添加快捷方式。快捷方式以应用程序命名（gateway 条目中的 app_name；如果文件来自 Code Browser，则使用文件名），并放在 Config 中设置的开始菜单文件夹内。如果快捷方式已经存在，就会更新它。
新构建完成后再次运行这些操作，以更新相同条目。如果复制失败，请关闭正在运行的应用程序后重试。这些操作与编译一样作为任务运行，因此会排在正在运行的编译任务之后。Open Compile Apps 打开 Compile Apps 文件夹。

Config 按照程序的工作流程从上到下排列。底部的 Save Settings 会将所有设置写入设置文件，并显示保存位置。
Code Browser（普通文件夹）：Default folder 是 Code Browser 首次打开的文件夹。Browse... 用于选择文件夹，Use Current 使用 Code Browser 当前显示的文件夹。Recent folders 按从新到旧的顺序列出已使用的文件夹，并保留最近 15 个。在 Code Browser 中打开的每个文件夹都会自动添加。输入或选择文件夹后，按 Add 将其加入列表，按 Remove 将其移除，或按 Open 在 Code Browser 中打开。
Gateway（源文件列表）：此文件列出 Gateway Apps 中的应用程序。Browse... 用于选择文件，Default 返回程序文件夹中的 gateway.json，Reload 重新读取文件。此处不会编译或复制任何内容。
Temp Compile：Output root 是 build、dist、spec 文件夹和任务日志的存放位置，每个应用程序各有一个文件夹。这些是用于测试的临时文件，不是最终应用程序。Python (PyInstaller) 是用于运行 PyInstaller 和 Python 测试的 python.exe。只有当本程序本身是 exe 时才需要它，因为 exe 无法运行 PyInstaller。留空则使用 PATH 中找到的 Python。
Compile Apps：Apps folder 是最终应用程序的存放位置，每个应用程序都有自己的文件夹，其中包含 exe 和设置 json。开始菜单快捷方式和新的 gateway 条目都指向此副本。Start Menu folder 是添加快捷方式的文件夹名称。使用 Browse... 选择新的 Apps 文件夹时，程序会询问是否也要将设置文件保存在该文件夹中。
如果本程序本身是 exe，英文帮助内容会嵌入其中。首次启动时，会在 exe 旁边放置一份副本供编辑；该副本不会被替换，删除后会恢复内置文本。其他语言的帮助文件是放在 exe 旁边的普通文件。
Settings file：显示本程序自身设置文件（python_compiler.json）的保存位置。初始位置与程序（exe 或此脚本）在同一文件夹中，绝不会放在临时文件夹内。Browse... 选择其他文件夹，Use Apps Folder 将设置文件移至 Compile Apps 文件夹，Default 将其移回程序文件夹。当前设置会保存到新位置，程序文件夹中会保留一条简短说明，指出设置文件的位置，以便下次启动时找到它。旧副本会保留在原处。如果启动时无法访问设置文件夹（例如网络驱动器不可用），程序会使用默认设置并保留该说明。
颜色、密度和窗口大小设置位于 UI Choices。

选择颜色主题、界面密度和窗口大小。Use Current Size 使用窗口当前大小；Apply + Save 应用并保存所选设置。列表条纹会遵循所选主题。这些设置控制应用程序的外观。文件夹和选项应在 Config 中设置。

使用共享启动器打开已注册的应用程序、文件、文件夹和链接。它将卡片保存在程序文件夹中的 gateway_cards.json 文件内。Gateway 与提供 Gateway Apps 列表的 gateway 文件是分开的。
